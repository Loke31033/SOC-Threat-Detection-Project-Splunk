SOC Threat Detection Project using Splunk
By: Lokeshwar V

This project simulates a real-world SOC Analyst investigation using Splunk, Windows Security Logs, and Sysmon logs.
Multiple attack scenarios are generated, ingested, detected, and analyzed using essential SPL queries.

🔍 Project Overview

This repository contains:

Simulated Windows & Sysmon logs

15 essential Splunk SPL queries

Incident timeline (CSV)

Screenshots of detections

Full SOC Investigation Report (PDF)

🛠️ Tools Used

Splunk Enterprise

Windows Security Logs

Sysmon (Process + Network logs)

CSV / Excel

GitHub
